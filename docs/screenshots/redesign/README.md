# Все экраны CRM · новый дизайн

Реальные скриншоты Chromium, mock API. Телефон 393 × 852 CSS px; десктоп 1440 × 1000 CSS px. Десктоп — полная высота страницы; телефон — реальные экраны с прокруткой и перекрытием, чтобы закреплённые кнопки не скрывали поля на длинном снимке. Каждый редактор и состояние снят отдельно.
