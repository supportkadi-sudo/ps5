# Учёт кабинок и продаж в Telegram

Небольшой Telegram-бот для сотрудников игрового клуба. Управление идёт через кнопки внутри чата; отдельная Mini App или веб-панель не нужны.

## Что уже работает

- Доступ только для Telegram ID из `ADMIN_IDS`.
- Добавление кабинок и индивидуального тарифа за час.
- Запуск и завершение сеанса; неполный час округляется вверх, минимум — один час.
- Добавление товаров с ценой и запись продажи с количеством.
- Сводка за текущий день по закрытым сеансам и продажам.
- PostgreSQL сохраняет данные между перезапусками.

## Запуск

1. Создайте бота у `@BotFather` и скопируйте токен.
2. Узнайте свой Telegram ID у бота, который показывает ID пользователя.
3. Скопируйте `.env.example` в `.env` и заполните `BOT_TOKEN` и `ADMIN_IDS`.
4. Запустите из папки проекта:

   ```sh
   docker compose up --build -d
   ```

5. Напишите боту `/start`.

Чтобы посмотреть журнал:

```sh
docker compose logs -f bot
```

Для остановки:

```sh
docker compose down
```

Данные PostgreSQL останутся в Docker volume. Не публикуйте `.env` и задайте свой `DB_PASSWORD` в `.env` перед запуском.

## Кнопки бота

- **Кабинки** — статус кабинок, время текущего сеанса, тариф, команды начала и остановки.
- **Добавить кабинку** — название и цена за час.
- **Товары** — список активных товаров.
- **Добавить товар** — название и цена.
- **Продать товар** — записать количество проданного товара.
- **Отчёт за сегодня** — сумма закрытых сеансов и продаж.

Команда `/cancel` отменяет ввод.

## Границы первой версии

Тариф считается по каждому начатому часу. Отчёт показывает записанную выручку, но не является бухгалтерским учётом. Нет складских остатков, редактирования/удаления записей, разделения по сотрудникам и защиты от одновременного запуска одного места двумя сотрудниками. Перед реальной эксплуатацией стоит добавить эти функции по фактическим правилам клуба и настроить резервную копию базы.
